# 豆包生成限制与本项目适配说明

核查日期：2026-10-22。主要依据为[豆包官方用户协议](https://www.doubao.com/legal/terms)，该页面标注更新日期为 2026-09-10、生效日期为 2026-09-17。本文概括已核实的通用条款；特定功能如有单独协议，依据第 2.5 条，以具体协议为准。

## 版权拒绝意味着什么

“抱歉，由于版权相关限制，暂时无法创作对应的内容，换其他主题试试吧。”表示豆包拒绝了这次内容生成。这段提示没有给出具体触发元素，不能据此判定某张图片已经构成侵权，也无法据此确认是提示词、参考图、人物、标识或其他因素触发。

通用协议没有给出完整的生成关键词黑名单、版权识别阈值或保证通过的素材清单。“新闻纸拼贴”“黑白半调”“分层视差”等视觉描述本身不能据此认定为禁止项目。排查时可以检查参考图中的人物照片、标识、已有作品片段及其授权，优先使用原创或获得授权的素材；这仍不构成平台审核通过的保证。

## 已核实的限制

| 范围 | 官方条款 | 对生成任务的影响 |
| --- | --- | --- |
| 素材与知识产权 | 第 9.3、10.3 条要求输入及传播内容不侵犯著作权、商标等权利，输入应具有知识产权或合法授权。 | 参考图、文字、音频等均需检查来源和授权范围。 |
| 人物与隐私 | 第 5.1.6、5.2.2（15）（17）、10.3 条涉及个人信息、隐私权、肖像权、名誉权等。 | 使用人物照片或声音时需核实相应权利，避免侵权、冒充或误导；协议不等于宣布所有真人素材一律禁止。 |
| 内容安全 | 第 5.2.2 条限制违法、恐怖主义、暴力色情、伤害未成年人、歧视仇恨、谣言、危险行为等内容。 | 合法授权的素材仍需符合内容规则；输入和输出均在规范范围内。 |
| 商业用途 | 第 2.2 条写明不得将输出用于商业用途，第 2.10 条授予非商业使用软件的权利；第 9.1 条说明公司不主张输出所有权。 | “不主张输出所有权”不能直接推导出无限制商用许可。商用前需核实适用的具体功能协议或另行授权。 |
| AI 标识 | 第 6.4 条要求发布、传播生成信息时显著标识或提示，不应删除、篡改、伪造 AI 标识。 | 生成成功后仍需按规则保留标识并作相应提示。 |
| 第三方集成 | 第 2.8、5.1.1、6.2、9.4 条涉及未经授权访问使用、第三方工具干扰运行、非法抓取及模拟下载等限制。 | 本项目的网页自动化适配本身不代表取得官方授权；正式集成应核实授权和所选官方接口的具体协议。 |

网页端与火山方舟 API 的具体模型、时长、分辨率、额度及授权条件应分别核实。不能把某个 API 的能力或商用条件直接套用到豆包网页端。项目中自行设置的每日次数是本地计数，不是豆包官方额度承诺。

## 本项目如何显示

- 读取与本次提示词绑定的豆包回复，识别明确的版权、肖像或隐私、内容安全拒绝及视频生成失败。
- 正常跟踪时等待回复稳定后结束任务；在对应镜头中直接显示失败原因和豆包原文，保留原对话和窗口入口。
- 拒绝结果保存到任务记录，刷新后仍可查看；明确失败计入失败数量，不再一直显示生成中。
- 内容拒绝不触发自动换号重发，本地额度也不会因该拒绝结果扣减。豆包端如何计算实际额度以官网为准。
- 检查并调整内容后，可由用户手动重试。

若认为内容被误判，可使用豆包内的反馈入口。用户协议第 2.11 条也列出了问题反馈联系方式；本文不替用户提交反馈或申诉。
